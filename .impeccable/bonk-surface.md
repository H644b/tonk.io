# Tonk independent client

The user requested an independent 1:1 Bonk.io replica with fullscreen, better usability, mods, and the existing native feature set, then explicitly named the product Tonk.io and requested Cloudflare Workers with Supabase, fast imported community map search, H644b owner administration, and host-controlled bot count/difficulty. The pinned original remains binding visual authority; this is a code-led extension of that established world, with no invented comp or direction roll. The hosting and tools extend the independent service without replacing the original visual system or third-party attribution.

## Direction contract

THESIS: Keep the actual game and native menus at the center of the experience. Extend the shipped client with independent services, viewport projection, and an optional workbench.

OWN-WORLD: Original Futura PT faces, teal title bars, brown controls, gray panels, native icons and game assets. The workbench inherits those materials and uses compact controls.

STORY: Enter as a guest or account, join or host a room, play the original physics game, then open tools only when needed. Player-facing copy uses direct labels and actionable state messages. Keep service provenance and parity limitations in operator/developer documentation; no development pitches in Help or Workbench.

FIRST VIEWPORT: The game frame fills the browser. Fullscreen and Workbench are real controls inside the native top navigation at every width. Help sits after Skins and before Friend List. XP progress belongs to the navigation identity. Workbench opens a 440px right drawer, or a scrolling full-width panel on phones. Closing it restores the whole playfield.

FORM: Direct source-based extension, selected by the user's pinned reference; seed key not applicable. Signature interaction: enter fullscreen without shrinking the canvas, then share a full code pack through native-styled consent. Native animation and physics remain; added controls use immediate, restrained state changes.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Review scope and limits

Review the original interface and added workbench for visual coherence, readability, responsive layout, controls and hierarchy. Do not equate visual review with full 1:1 service or simulation certification. Private backend eligibility/ranking policy, the global community database, every possible mode/map/input combination, WAN and physical mobile touch play remain outside verified coverage. See docs/COVERAGE.md.

Original source assets remain byte-preserved; provenance is tracked by evidence manifests instead of editing the original image metadata. No generated raster assets were used.
