# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by the user. TypeScript/Node.js independent HTTP and Socket.IO server; locally preserved Bonk browser engine, plain HTML/CSS/JavaScript shell.
## Users
Bonk.io players seeking the existing game with fullscreen play and custom mods.
## Product Purpose
An independent 1:1 replica of Bonk.io, preserving original physics, interfaces, editors, modes, and existing feature scope, with true fullscreen and extensibility.
## Operating Context
Self-hosted multiplayer, with its own room directory and persistence. User explicitly chose an independent server rather than enhancing the official services.
## Capabilities and Constraints
Use original runtime evidence as acceptance criteria. Distinguish implemented and verified from partial or absent. Official accounts and community data do not become locally owned data. Runtime reuse must retain attribution and provenance.
## Brand Commitments
Bonk.io is the binding visual and behavioral reference. Build directly from the reference, per user approval.
## Evidence on Hand
Original HTML, shipped JavaScript, GameResources, and asset manifest under evidence/original. Original website inspected in a browser. Manifold provides a public compatibility protocol reference.
## Product Principles
- Preserve observed behavior and mechanics.
- Give the game the entire viewport.
- Own local service state and multiplayer routing.
- Make mod activation explicit and reversible.
- Report parity gaps honestly.
